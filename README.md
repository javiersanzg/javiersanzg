# Javier Sanz García

Business Administration student at EDEM in Valencia. I build LLM systems, agents and automations, and I test whether they actually work.

My focus is the gap between a business process and a working AI system: finding what is worth automating, building it, and measuring the result. I build with Claude Code. I set the architecture, the rules and the tests, and AI writes most of the code. Changes have to pass their tests before they are merged, and the risky ones get an independent review first.

### What I work on

- **LLM systems and agents.** Multi-agent workflows with defined roles, budgets and stop conditions.
- **Evaluation.** Golden sets, regression suites and champion/challenger tests, so a prompt or an agent only changes when it measurably improves.
- **Knowledge and retrieval (RAG).** A personal knowledge base on Git, with schemas, retrieval and source tracking for everything it takes in.
- **Process automation.** In a 2026 finance internship I mapped the supplier invoice process, built tools with Power Automate, Python and Excel VBA, and fixed broken queries in a live Power BI dashboard.
